# Security

## What counts

- The installers (`install/`) writing, deleting or linking files outside the places they document.
- A rule or skill that leads agents to leak secrets, skip an approval step, or run something destructive without asking.
- Secrets or private data committed to this repo.

## How to report

Do not open a public issue. Use GitHub's private reporting instead: **Security** tab → **Report a vulnerability** ([link](https://github.com/Eurie92/Agent-kit/security/advisories/new)).

Include what you ran, what happened, and what you expected. You should get a reply within 7 days. Fixes ship in a patch release, and the reporter is credited unless they ask not to be.

## Supported versions

Only the latest release gets fixes.
